Desarrollador Full Stack

Me describo como un desarrollador que disfruta entender el sistema completo: cómo la base de datos, la API y la interfaz trabajan juntas. Me enfoco en arquitecturas de microservicios, autenticación segura y experiencias de usuario cuidadas al detalle.
